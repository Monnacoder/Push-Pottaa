# Commit Crimes — first tester launch kit

## Goal
Recruit 10 developer teams to try the free prototype and tell us whether they would keep it installed. This is validation, not a revenue promise.

## Public positioning
**Commit Crimes — കോഡ് പുഷ് ചെയ്തോ? ഇനി കരഞ്ഞോ.**
A Malayalam-first GitHub-to-Slack roast bot. Every push gets a tiny, affectionate code roast. The joke targets code and build events, not someone's identity or personal life.

## Reddit / developer community post (use only where self-promotion is allowed)

**Title:** I made a Malayalam-first GitHub roast bot. Would your team actually use this?

**Body:**
I’m testing a tiny side project called Commit Crimes — “കോഡ് പുഷ് ചെയ്തോ? ഇനി കരഞ്ഞോ.” It turns GitHub pushes, failed builds and PR events into Malayalam/Manglish roast messages in Slack.

Examples:
- “കോഡ് പുഷ് ചെയ്തു. ഇനി QA-യുടെ പ്രാർത്ഥന തുടങ്ങാം. 🙏💀”
- “Build ചത്തു. കാരണം അന്വേഷിക്കണ്ട, commit history തുറന്നാൽ മതി. 🪦”
- “PR merge ആയി. ഇനി bug-ന് പുതിയ വീട്: production. 🪦”

The demo is ready; the live integration still needs setup and testing. I’m looking for a few teams who like dark developer humour and would be willing to try it in a private test channel. The bot should not read source code; it uses event metadata. Feedback welcome, especially what would make this useful (or annoying enough to uninstall).

## Direct message to a potential tester

Hey! I’m testing a small Malayalam-first GitHub-to-Slack roast bot called Commit Crimes. It posts silly Malayalam/Manglish roasts on code pushes and build events. Would you be open to trying it in a private test repo/channel and telling me if it’s funny or annoying? No pressure, and please don’t connect a production repo for the first test.

## Questions to ask testers
1. Was setup clear enough to finish without a call?
2. Did the roast make you or a teammate laugh?
3. Would you leave it enabled after the novelty wears off?
4. What should trigger a roast: every push, failed build, opened PR, merged PR, or deployment?
5. Would your team pay for custom roast packs or team controls? If yes, what price feels reasonable?
6. What would make you uninstall it immediately?

## Success criteria for the first test
- 10 teams try or seriously evaluate the demo.
- 5 teams complete a real test in a private channel.
- 3 teams keep it enabled for two weeks.
- At least 2 teams express concrete willingness to pay for a specific feature.

If these fail, do not spend on ads or add billing yet. Learn what people actually want first.

## Where to recruit
- Relevant Malayalam/Kerala developer groups where promotion is permitted.
- GitHub communities and developer Discord servers with a showcase or projects channel.
- Reddit communities only after checking their self-promotion rules.
- LinkedIn from a brand-only page; be transparent that it is an early prototype.
- Indie-maker/product-feedback communities that welcome early-stage tools.

Never spam people, pretend to have customers, or claim that the app is live before the integration has been deployed and tested.
