Privacy notice (draft)

This draft describes the current MVP. The project owner must add a support contact and verify hosting and log-retention details before wider use.

Data processed

When a GitHub repository is connected, Push Pottaa receives signed webhook event details such as repository name, sender, event type, branch, commit or pull-request title, and a link to the GitHub page. It verifies the webhook signature and does not clone repositories or read source files.

Where data goes

For supported events, event metadata and the generated Therivili message are sent to the Slack channel configured by the service owner. The app does not keep an event database. Render may process service logs, and Slack messages follow the workspace’s retention settings.

Secrets

GitHub webhook secrets and Slack webhook URLs must stay in private environment settings. Never put them in source files, issue reports, screenshots, or chat.

Contact and review

This is a starter draft, not a final legal policy. Add the project operator’s contact details and review the wording against the actual deployment before relying on it.
