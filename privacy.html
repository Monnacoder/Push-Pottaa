What the prototype does

The local demo generates roast text in your browser. It does not connect to GitHub, read source code, or transmit demo activity.

Planned integration data

The server integration is designed to process GitHub webhook metadata such as repository name, sender username, event type, branch, commit or pull-request title, and a link to the relevant GitHub page. It does not need source-code contents. When configured, it forwards a roast and limited event metadata to a Slack incoming webhook.

Secrets and retention

Webhook secrets and Slack webhook URLs must be stored as private environment variables and never committed to source control. Before launch, document log retention, deletion procedures, hosting region, access controls, and how users can request support or deletion.
